The Java Color class includes both static (class-level) attributes for common colors and non-static (instance-level) attributes that represent specific color values.

You can explore Java source code directly in an IDE like IntelliJ by navigating into classes and methods, which helps understand how built-in classes work.

Static attributes provide default colors accessible via the class, while instance methods let you manipulate and retrieve color details for specific objects.

Using instance methods with objects allows you to perform actions like making a color brighter or darker, demonstrating how behavior is tied to instances.
